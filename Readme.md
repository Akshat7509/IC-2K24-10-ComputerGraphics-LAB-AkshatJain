## 📚 About the Repository

This repository contains the **Computer Graphics and Multimedia Lab** programs, practical assignments, and lab activities completed as part of the **Computer Graphics Lab** course.

The repository covers fundamental concepts of Computer Graphics, including:

- Graphics Primitives
- Line Drawing Algorithms
- Circle Drawing Algorithms
- 2D Transformations
- Polygon Operations
- Clipping Algorithms
- Basic Graphical Techniques
- Other Computer Graphics and Multimedia Practical Programs
